# محاسبات نفوذ آب در خاک — اپ قابل نصب (PWA)

اپ وب فارسی/انگلیسی برای محاسبه و تخمین پارامترهای نفوذ (SCS، Philip، Kostiakov)، با نمودار، گزارش چاپی/PDF و ذخیره‌ی پروژه‌ها در مرورگر.
بدون سرور و بدون نیاز به build؛ فقط فایل‌های ثابت (HTML/CSS/JS).

## ساختار
- `index.html` — صفحه‌ی اصلی (گلدان و لایه‌های خاک)
- `style.css` — ظاهر و انیمیشن‌ها
- `engine.js` — محاسبات (مستقل از رابط کاربری): مدل‌ها، تخمین پارامترها، واحدها
- `app.js` — رابط کاربری، ترجمه‌ها (FA/EN)، پروژه‌ها، گزارش
- `sw.js` + `manifest.webmanifest` + `icon-*.png` — نصب‌پذیری و کار آفلاین
- `test.js` — آزمون‌های محاسبات

## اجرا روی کامپیوتر
```
python -m http.server 8000      # یا: npx serve
```
بعد در مرورگر: `http://localhost:8000`
(سرویس‌ورکر فقط روی `localhost` یا HTTPS کار می‌کند؛ با باز کردن مستقیم فایل `index.html` نصب و آفلاین کار نمی‌کند.)

## آزمون محاسبات
```
node test.js
```

## گذاشتن روی اینترنت (برای نصب روی گوشی)
یکی از این‌ها (همه رایگان و HTTPS هستند):
1. **Netlify Drop:** پوشه را روی netlify.com/drop بکشید.
2. **GitHub Pages:** فایل‌ها را در یک repo بگذارید و Pages را روشن کنید.
3. **Cloudflare Pages / Vercel:** پوشه را به‌عنوان پروژه‌ی static آپلود کنید.

## نصب روی گوشی
- **اندروید (Chrome):** باز کردن آدرس ← منو (⋮) ← «Install app / نصب برنامه» (یا دکمه‌ی نصب داخل «راهنما»).
- **آیفون (Safari):** دکمه‌ی Share ← «Add to Home Screen».

## نکته‌ها و محدودیت‌ها
- فونت Vazirmatn از Google Fonts بارگذاری می‌شود و بعد از اولین بازدید ذخیره می‌شود؛ بدون آن فونت سیستم استفاده می‌شود.
- فرم SCS در برنامه `Z = a·t^b + c` است؛ پیش از استفاده در تمرین با جزوه‌ی استاد تطبیق دهید (فقط `scs` در `engine.js` را تغییر دهید).
- عدد «جبهه‌ی رطوبت» در لایه‌ها فقط نمایشی است و به نتیجه‌ی مدل وصل نیست.
- پروژه‌ها در localStorage همین مرورگر/دستگاه ذخیره می‌شوند.
